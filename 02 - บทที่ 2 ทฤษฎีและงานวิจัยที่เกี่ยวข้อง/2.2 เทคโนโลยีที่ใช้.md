# 2.2 เทคโนโลยีที่ใช้ (Technologies Used)

รายละเอียดโครงสร้างทางเทคนิค เครื่องมือ และเทคโนโลยีที่ถูกเลือกใช้งานในโครงการ

---

## 📝 คำแนะนำในการเขียน
*   ควรระบุเวอร์ชันและเหตุผลที่เลือกใช้เทคโนโลยีดังกล่าว (ความเสถียร ประสิทธิภาพ ความคุ้นเคยของทีม เป็นต้น)
*   **ตัวอย่างโครงสร้างย่อย**:
    *   **Frontend**: React (v18)
    *   **Backend**: Node.js & Express
    *   **Database**: PostgreSQL
    *   **DevOps / Infrastructure**: Docker, GitHub Actions
