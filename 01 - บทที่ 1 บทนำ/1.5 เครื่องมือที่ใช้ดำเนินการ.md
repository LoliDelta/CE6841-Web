# 1.5 เครื่องมือที่ใช้ดำเนินการ (Development Tools)

การวิจัยและออกแบบระบบสั่งอาหารออนไลน์ใช้เครื่องมือและเทคโนโลยีสนับสนุนการดำเนินงานดังนี้:

### 1.5.1 ด้านฮาร์ดแวร์ (Hardware Tools)
1.  **เครื่องคอมพิวเตอร์แม่ข่ายจำลองและทดสอบ (Local Development Server)**:
    *   หน่วยประมวลผลกลาง (CPU): สถาปัตยกรรม x64 ความเร็วไม่น้อยกว่า 2.5 GHz แบบ Multi-core
    *   หน่วยความจำเข้าถึงโดยสุ่ม (RAM): ขนาดไม่น้อยกว่า 16 GB เพื่อรองรับการทำงานของเครื่องมือจำลองเซิร์ฟเวอร์และฐานข้อมูลพร้อมกัน
2.  **อุปกรณ์ปลายทางสำหรับทดสอบผู้ใช้ (Target Clients)**:
    *   อุปกรณ์สมาร์ตโฟนระบบปฏิบัติการ Android และ iOS (เพื่อทดสอบการตอบสนองแบบ Responsive Web บนจอสัมผัส)
    *   เครื่องคอมพิวเตอร์ตั้งโต๊ะและแล็ปท็อป (เพื่อทดสอบเว็บเบราว์เซอร์หลัก ได้แก่ Google Chrome, Safari และ Mozilla Firefox)

### 1.5.2 ด้านซอฟต์แวร์และโครงสร้างพื้นฐาน (Software & Technical Stack)
1.  **เทคโนโลยีส่วนหน้าบ้านและส่วนติดต่อผู้ใช้ (Frontend Tech Stack)**:
    *   **HTML5, CSS3, JavaScript / TypeScript**: ภาษาหลักในระดับโครงสร้างเว็บแอปพลิเคชัน
    *   **React.js (หรือ Next.js Framework)**: คลังไลบรารี JavaScript ในการเขียนระบบแบบคอมโพเนนต์ (Component-based architecture) ช่วยให้การอัปเดตสถานะของ UI ฝั่งผู้ใช้เป็นไปอย่างลื่นไหลและประหยัดการรีเฟรชหน้าเว็บ
    *   **Tailwind CSS**: เฟรมเวิร์กจัดการสไตล์แผ่นสไลด์การออกแบบ ช่วยให้การทำหน้าเว็บมีโครงสร้างเป็นแบบ Responsive สะดวกรวดเร็วตามกฎ Mobile-first Design
2.  **เทคโนโลยีส่วนหลังบ้านและตรรกะธุรกิจ (Backend Tech Stack)**:
    *   **Node.js & Express.js** (หรือ **Python & FastAPI**): สภาพแวดล้อมและเฟรมเวิร์กสำหรับการพัฒนา RESTful API ในการเชื่อมต่อ จัดการคำสั่งซื้อ และจัดการสิทธิ์ผู้ใช้งาน
    *   **Socket.io (WebSockets Protocol)**: โมดูลโปรโตคอลการสื่อสารหลักสำหรับการทำงานเรียลไทม์ระหว่างส่วนหน้าบ้านและหลังบ้าน ทำให้เซิร์ฟเวอร์สามารถผลักข้อมูล (Data Push) ไปยังส่วนบริหารจัดการคำสั่งซื้อของพนักงานร้านได้ทันที
3.  **ระบบจัดการฐานข้อมูล (Database Management System: DBMS)**:
    *   **MongoDB (NoSQL)** หรือ **PostgreSQL (RDBMS)**: ใช้ในการจัดเก็บโครงสร้างข้อมูลเอกสารเมนูอาหาร บัญชีผู้ใช้ และประวัติการทำธุรกรรมสั่งซื้อ
4.  **เครื่องมือทดสอบประสิทธิภาพและการจำลองสภาพแวดล้อม (Testing & DevOps Tools)**:
    *   **Docker & Docker Compose**: ใช้ในการสร้างตู้คอนเทนเนอร์ (Containerization) เพื่อจำลองเซิร์ฟเวอร์ API และฐานข้อมูลให้พร้อมรันเหมือนในสภาพแวดล้อมจริง
    *   **Postman**: เครื่องมือจำลองการเรียกใช้งานและตรวจสอบความถูกต้องของ API endpoint ฝั่งหลังบ้าน
    *   **k6** หรือ **Apache JMeter**: เครื่องมือทดสอบประสิทธิภาพการรับแรงโหลดและการตอบสนองของระบบภายใต้คำสั่งจำลองผู้ใช้งานพร้อมๆ กัน (Load and Stress Testing)
5.  **เครื่องมือสนับสนุนการเขียนเอกสารและจัดโครงร่างโครงการ**:
    *   **Git & GitHub**: ระบบควบคุมรุ่นของรหัสซอร์สโค้ด (Version Control)
    *   **Obsidian**: ใช้ในการบริหารจัดการโครงร่างรายงานโครงงานและรวบรวมข้อเสนอแนะเชิงวิชาการ
