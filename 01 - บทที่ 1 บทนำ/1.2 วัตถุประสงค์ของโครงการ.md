# 1.2 วัตถุประสงค์ของโครงการ (Project Objectives)

การดำเนินโครงการพัฒนาเว็บแอปพลิเคชันสั่งอาหารออนไลน์ มีวัตถุประสงค์การวิจัยและการดำเนินงานดังนี้:

1.  **เพื่อออกแบบและพัฒนาส่วนติดต่อผู้ใช้งานแบบตอบสนอง (Responsive User Interface)**
    *   เพื่อสร้างระบบสั่งอาหารฝั่งลูกค้าที่รองรับการใช้งานบนทุกอุปกรณ์ (สมาร์ตโฟน แท็บเล็ต และคอมพิวเตอร์) ช่วยให้ผู้ใช้สามารถค้นหา เลือกรายการอาหาร จัดการตะกร้าสินค้า และยืนยันคำสั่งซื้อได้อย่างมีประสิทธิภาพ
2.  **เพื่อออกแบบและพัฒนาระบบหลังบ้านสำหรับการจัดการคำสั่งซื้อแบบเรียลไทม์ (Real-time Order Management System)**
    *   เพื่อพัฒนาระบบส่งผ่านข้อมูลคำสั่งซื้อจากลูกค้าไปยังห้องครัวของร้านอาหารทันทีผ่านเทคโนโลยีการสื่อสารแบบสองทิศทาง (Bi-directional Communication) ลดเวลาการประมวลผลคำสั่งซื้อ
3.  **เพื่อสร้างระบบฐานข้อมูลที่มีเสถียรภาพและระบบความปลอดภัยสำหรับข้อมูลร้านค้า**
    *   เพื่อจัดเก็บบันทึกข้อมูลรายการอาหาร หมวดหมู่ ประวัติการสั่งซื้อ และข้อมูลบัญชีผู้ใช้งาน พร้อมทั้งพัฒนาระบบสิทธิ์การเข้าถึงข้อมูลตามบทบาทผู้ใช้ (Role-based Access Control: RBAC)
4.  **เพื่อประเมินประสิทธิภาพและระดับความพึงพอใจในการใช้งานระบบ (System Evaluation)**
    *   เพื่อศึกษาอัตราการตอบสนองความเร็วของระบบ (Response Time) และประเมินระดับความพึงพอใจจากกลุ่มตัวอย่างผู้รับบริการและผู้ประกอบการร้านอาหารหลังจากทดลองใช้งานระบบจริง
