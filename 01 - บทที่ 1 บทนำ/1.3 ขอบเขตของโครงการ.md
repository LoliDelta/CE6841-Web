# 1.3 ขอบเขตของโครงการ (Project Scope)

ขอบเขตของการดำเนินโครงการพัฒนาแอปพลิเคชันระบบสั่งอาหารออนไลน์ มีรายละเอียดเชิงเทคนิคและการดำเนินงานดังต่อไปนี้:

### 1.3.1 ขอบเขตด้านบทบาทผู้ใช้งาน (User Roles)
ระบบแบ่งสิทธิ์การเข้าถึงข้อมูลและการใช้งานออกเป็น 2 กลุ่มหลัก ได้แก่:
1.  **กลุ่มผู้ใช้บริการทั่วไป (Customer/Client)**: สามารถเข้าใช้งานระบบโดยไม่ต้องติดตั้งโปรแกรมเพิ่มเติมผ่านเบราว์เซอร์ เพื่อดูเมนู สั่งสินค้า และติดตามสถานะคำสั่งซื้อ
2.  **กลุ่มผู้ดูแลระบบและร้านค้า (Administrator/Restaurant Staff)**: ผู้ประกอบการและพนักงานในร้านอาหาร ที่ทำหน้าที่จัดการข้อมูลเมนูอาหาร รับรายการสั่งซื้อ และตรวจสอบรายงานสถิติยอดขาย

### 1.3.2 ขอบเขตด้านฟังก์ชันการทำงานของระบบ (System Functionality)
1.  **ระบบย่อยสำหรับฝั่งผู้ใช้บริการ (Customer Module)**:
    *   **ระบบสมัครสมาชิกและลงชื่อเข้าใช้งาน (User Authentication)**: รองรับการลงทะเบียนด้วยอีเมล และจัดเก็บบัญชีผู้ใช้ด้วยการเข้ารหัสข้อมูลรหัสผ่านที่ปลอดภัย (Hashing)
    *   **ระบบแสดงข้อมูลและค้นหาอาหาร (Menu Catalog & Search)**: แสดงรายการอาหารแยกตามหมวดหมู่ ค้นหาเมนูอาหาร และกรองรายการอาหารตามเงื่อนไข (เช่น อาหารแนะนำ ราคา หรือประเภทอาหาร)
    *   **ระบบจัดการตะกร้าสินค้า (Cart Management)**: สามารถเลือกอาหาร เพิ่ม/ลดจำนวน แก้ไขตัวเลือกเสริม (เช่น ความเผ็ด ขนาดพิเศษ) และคำนวณราคาสุทธิรวมค่าบริการแบบเรียลไทม์
    *   **ระบบชำระเงินจำลอง (Simulated Payment Gateway)**: แสดงผลการสร้างรหัสคิวอาร์ (QR Code) มาตรฐานการชำระเงิน PromptPay และปุ่มจำลองการยืนยันการชำระเงิน
    *   **ระบบติดตามสถานะคำสั่งซื้อ (Order Tracking)**: แจ้งเตือนสถานะการดำเนินการของคำสั่งซื้อของตนเองตั้งแต่ขั้นตอนการรับออร์เดอร์ การปรุงอาหาร จนถึงการจัดส่งสำเร็จ
2.  **ระบบย่อยสำหรับผู้ดูแลร้านค้า (Administrator Module)**:
    *   **แผงควบคุมการรับรายการสั่งซื้อแบบเรียลไทม์ (Real-time Order Dashboard)**: หน้าจอแสดงคำสั่งซื้อที่เข้ามาใหม่ พร้อมระบบแจ้งเตือนด้วยเสียง และการจัดการเปลี่ยนสถานะคำสั่งซื้อ (เช่น กำลังเตรียมอาหาร -> อาหารเสร็จสิ้น -> พร้อมส่งมอบ)
    *   **ระบบจัดการเมนูและหมวดหมู่ (Content Management System: CMS)**: สามารถ เพิ่ม ลบ แก้ไข ข้อมูลรายการอาหาร ราคา รูปภาพประกอบ และการตั้งค่าสถานะอาหารหมดชั่วคราว
    *   **ระบบวิเคราะห์ยอดขายและรายงานเชิงภาพ (Analytics Dashboard)**: แสดงสรุปยอดขาย ประจำวัน ประจำเดือน และเมนูยอดนิยม 5 อันดับแรกในรูปแบบแผนภูมิและกราฟ (Data Visualization)

### 1.3.3 ขอบเขตด้านข้อจำกัดและสิ่งที่ไม่ครอบคลุม (Out of Scope / Limitations)
1.  **การติดตามเส้นทางส่งอาหารเชิงตำแหน่ง (GPS Tracking)**: ระบบนี้ไม่ครอบคลุมระบบนำทางแผนที่ดาวเทียมแบบเรียลไทม์สำหรับพนักงานส่งอาหารภายนอก แต่จะแสดงเฉพาะสถานะขั้นตอนการจัดส่ง (เช่น กำลังนำส่ง/ส่งเรียบร้อยแล้ว)
2.  **การเชื่อมต่อกับเครื่องพิมพ์ใบเสร็จทางกายภาพ (Thermal POS Printer)**: ระบบจะแสดงผลใบเสร็จรับเงินในรูปแบบดิจิทัล (E-Receipt) บนหน้าจอของเว็บไซต์เท่านั้น โดยไม่มีการจัดทำไดรเวอร์เพื่อเชื่อมต่อไปยังเครื่องพิมพ์ใบเสร็จความร้อนทางกายภาพโดยตรง
3.  **การรับรองการชำระเงินจริงร่วมกับธนาคารพาณิชย์**: การทำธุรกรรมทางการเงินในส่วนของ PromptPay จะใช้ระบบคิวอาร์โค้ดจำลองความถูกต้องตามมาตรฐาน เพื่อความปลอดภัยและหลีกเลี่ยงข้อจำกัดการขอใช้ใบอนุญาต API ของสถาบันการเงินจริงในขั้นตอนทดสอบ
