## 🚀 วิธีนำไปรันใน VS Code (ไม่ให้มีบัค)

สามารถเปิดรันได้ **3 วิธี** (รองรับการเปิดทั้งจากโฟลเดอร์หลัก `Projact Web CE6841` หรือโฟลเดอร์ย่อย `ksu-delivery`):

### วิธีที่ 1: รันผ่าน Terminal ใน VS Code (ง่ายที่สุด)
1. เปิดโปรแกรม **VS Code** แล้วไปที่เมนู **File > Open Folder...** เลือกโฟลเดอร์ `Projact Web CE6841`
2. เปิด Terminal ใน VS Code (กดปุ่ม `` Ctrl + ` `` หรือเมนู **Terminal > New Terminal**)
3. พิมพ์คำสั่ง:
   ```bash
   npm run dev
   ```
4. กด `Ctrl + คลิก` ที่ลิงก์ **`http://localhost:5173/`** เพื่อเปิดดูหน้าเว็บ

### วิธีที่ 2: รันผ่านปุ่ม Run Task ของ VS Code
1. ใน VS Code กดปุ่ม `Ctrl + Shift + P`
2. พิมพ์เลือก **`Tasks: Run Build Task`** (หรือกด `Ctrl + Shift + B`)
3. ระบบจะรันเซิร์ฟเวอร์ `KSU Delivery Dev Server` ให้อัตโนมัติ

### วิธีที่ 3: ดับเบิลคลิกไฟล์ `start-web.bat`
* ดับเบิลคลิกไฟล์ **`start-web.bat`** ในโฟลเดอร์หลัก ระบบจะทำการเช็คแพ็กเกจ รันเซิร์ฟเวอร์ และเด้งเปิดหน้าเว็บ `http://localhost:5173` ให้ทันที
